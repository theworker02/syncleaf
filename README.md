# syncleaf

Sync encode/decode helpers for leaf payloads in pipelines.

**Site:** https://theworker02.github.io/syncleaf/

## Install / run

```bash
git clone https://github.com/theworker02/syncleaf.git
cd syncleaf
node src/cli.js
node --test
```
